1. Latar Belakang
Jaringan komputer memungkinkan berbagai perangkat saling berkomunikasi melalui alamat IP dan port tertentu. Port digunakan sebagai endpoint komunikasi bagi layanan yang berjalan pada suatu host. Informasi mengenai port yang terbuka dapat memberikan gambaran mengenai layanan yang tersedia pada suatu sistem dan dapat menjadi informasi awal dalam proses pengenalan terhadap target jaringan.
Port scanning merupakan aktivitas untuk memeriksa port pada suatu host atau jaringan guna mengetahui port yang terbuka maupun layanan yang tersedia. Dalam konteks keamanan jaringan, port scanning dapat menjadi salah satu aktivitas awal sebelum dilakukan serangan lanjutan karena hasil pemindaian dapat memberikan informasi mengenai alamat IP aktif, port yang tersedia, serta layanan yang dapat diakses. Penelitian Al Hilmi dan Khujaemah (2022) menunjukkan bahwa port scanning merupakan salah satu aktivitas yang perlu diperhatikan dalam pemantauan keamanan jaringan dan dapat dilakukan menggunakan alat seperti Nmap untuk memeriksa port yang tersedia pada target.
Aktivitas port scanning menghasilkan pola traffic yang berbeda dari sebagian traffic normal. Pada pemindaian yang dilakukan secara cepat, satu source IP dapat mengirimkan sejumlah probe atau koneksi menuju beberapa destination port dalam waktu tertentu. Penelitian Wu et al. (2023) menunjukkan bahwa jumlah port yang diminta oleh suatu source IP dalam interval waktu dapat digunakan sebagai salah satu karakteristik untuk mendeteksi port scanning. Penelitian tersebut juga menjelaskan bahwa pemindaian yang dilakukan secara cepat relatif lebih mudah dikenali, sedangkan pemindaian dengan interval probe yang lebih panjang dapat menjadi lebih sulit dideteksi.
Selain berdasarkan jumlah destination port, karakteristik waktu juga perlu diperhatikan dalam proses deteksi. Port scanning dapat dilakukan secara perlahan dengan memberikan jeda antar probe sehingga pola traffic tidak terlihat sebagai aktivitas dengan intensitas tinggi. Wu et al. (2022) membahas pendeteksian slow port scan yang berlangsung dalam durasi panjang dan menunjukkan bahwa pola scanning dengan interval yang lebih panjang menjadi tantangan bagi sistem deteksi.
Kondisi tersebut menunjukkan bahwa penggunaan satu parameter atau satu nilai threshold saja belum tentu dapat mengenali seluruh pola port scanning. Threshold yang terlalu rendah berpotensi menyebabkan traffic normal yang memiliki banyak koneksi dianggap sebagai port scanning. Sebaliknya, threshold yang terlalu tinggi dapat menyebabkan scanning dengan jumlah port atau intensitas rendah tidak terdeteksi. Oleh karena itu, analisis beberapa karakteristik traffic, seperti source IP, destination IP, destination port, TCP flags, timestamp, jumlah port yang berbeda, jumlah koneksi, dan interval koneksi, dapat digunakan sebagai dasar dalam membangun aturan deteksi.
Penelitian mengenai implementasi IDS dan IPS juga menunjukkan bahwa TCP port scanning dapat diuji dalam lingkungan jaringan terkontrol untuk melihat kemampuan sistem dalam mengenali aktivitas mencurigakan. Razzanda dan Koprawi (2024), misalnya, melakukan pengujian IDS dan IPS terhadap serangan TCP port scanning pada lingkungan pengujian dan mengevaluasi kemampuan sistem dalam mendeteksi aktivitas tersebut.
Berdasarkan permasalahan tersebut, penelitian ini mengembangkan aplikasi deteksi port scanning berbasis Python dengan pendekatan analisis karakteristik traffic jaringan. Aplikasi mengambil informasi berupa source IP, destination IP, destination port, protocol, TCP flags, dan timestamp, kemudian melakukan pengelompokan traffic serta menghitung jumlah destination port yang berbeda, jumlah koneksi, dan interval koneksi. Hasil karakteristik tersebut digunakan dalam rule-based detection untuk menentukan apakah suatu pola traffic termasuk normal atau port scanning. Scapy digunakan sebagai library untuk menangkap dan menganalisis paket jaringan.
Pengujian dilakukan menggunakan traffic normal dan beberapa variasi port scanning. Variasi pengujian meliputi jumlah port yang dipindai, interval antarprobe, dan durasi scanning. Setiap skenario memiliki ground truth sehingga hasil deteksi aplikasi dapat dibandingkan dengan kondisi sebenarnya. Hasil tersebut digunakan untuk memperoleh nilai True Positive (TP), True Negative (TN), False Positive (FP), dan False Negative (FN).
Selanjutnya, hasil pengujian digunakan untuk menghitung Detection Rate, False Positive Rate, False Negative Rate, dan Detection Time. Evaluasi tersebut digunakan untuk mengetahui kemampuan rule yang dikembangkan dalam mendeteksi port scanning pada berbagai karakteristik traffic. Dengan demikian, penelitian ini tidak hanya menghasilkan aplikasi deteksi port scanning, tetapi juga memberikan evaluasi terhadap kemampuan pendekatan rule-based dalam mengenali pola port scanning berdasarkan karakteristik traffic jaringan.


2. Rumusan Masalah
1. Bagaimana mengembangkan aplikasi berbasis Python untuk menangkap dan menganalisis karakteristik traffic port scanning?
2. Karakteristik traffic apa saja yang dapat digunakan sebagai dasar rule-based detection untuk port scanning?
3. Bagaimana kemampuan aplikasi dalam mendeteksi port scanning dengan variasi jumlah port dan interval scanning?
4. Bagaimana nilai Detection Rate, False Positive Rate, False Negative Rate, dan Detection Time yang dihasilkan aplikasi?
3. Batasan Masalah
1. Penelitian berfokus pada port scanning berbasis traffic jaringan.
2. Penelitian tidak menggunakan Machine Learning atau Deep Learning.
3. Penelitian menggunakan pendekatan rule-based detection.
4. Penelitian berfokus pada IPv4 dan traffic TCP.
5. Parameter yang dianalisis meliputi source IP, destination IP, destination port, TCP flags, timestamp, jumlah destination port berbeda, jumlah koneksi, dan interval koneksi.
6. Penelitian tidak menganalisis payload aplikasi.
7. Pengujian dilakukan dalam lingkungan jaringan yang terisolasi dan dikendalikan.
8. Traffic penelitian terdiri dari traffic normal dan traffic port scanning.
9. Variasi pengujian meliputi jumlah port, interval scanning, dan durasi scanning.
10. Evaluasi menggunakan TP, TN, FP, FN, Detection Rate, False Positive Rate, False Negative Rate, dan Detection Time.
11. Penelitian tidak membahas eksploitasi vulnerability setelah port ditemukan.


4. Tujuan Penelitian
1. Mengembangkan aplikasi berbasis Python untuk menangkap dan menganalisis traffic jaringan.
2. Mengidentifikasi karakteristik traffic yang digunakan sebagai dasar deteksi port scanning.
3. Mengimplementasikan rule-based detection untuk mendeteksi port scanning.
4. Menguji aplikasi menggunakan traffic normal dan beberapa variasi port scanning.
5. Mengukur Detection Rate, False Positive Rate, False Negative Rate, dan Detection Time.
6. Menganalisis pengaruh variasi jumlah port, interval scanning, dan durasi scanning terhadap kemampuan deteksi.




5. Manfaat Penelitian
1. Menghasilkan aplikasi sederhana untuk mendeteksi aktivitas port scanning.
2. Memberikan hasil evaluasi kuantitatif mengenai rule-based detection untuk port scanning.
3. Memberikan informasi mengenai karakteristik traffic yang dapat digunakan untuk mendeteksi aktivitas scanning.
4. Menjadi referensi untuk penelitian network security berbasis traffic analysis.
5. Menerapkan konsep jaringan komputer, TCP, network security, packet analysis, dan Python.


Catatan:
* Karena aplikasi menganalisis interval waktu dan menghitung port unik per source IP (sliding time window), perlu dijelaskan struktur data yang digunakan (misalnya hash table dengan TTL/Time-To-Live) agar memori tidak mengalami kebocoran (memory leak) ketika aplikasi berjalan dalam durasi lama.
* Sebutkan jenis port scanning yang akan diuji menggunakan tool apa ? untuk memperjelas variasi data uji.
